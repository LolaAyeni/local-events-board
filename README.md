# Local Events Board

Local Events Board is a small web application for discovering and sharing events happening in a local community.

## Current status

The initial React and Vite project setup is complete. Event browsing, filtering, details, and submission features will be added in later steps.

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

## Create a production build

```bash
npm run build
```
